# Zelmyra Website

## Run locally
```cmd
cd C:\Users\02all\Documents\zelmyra-website
npm install
npm run dev
```

Open: http://localhost:3000

## Images
Put required images in `public/images`.
For gallery screenshots, use `public/images/gallery` and the gallery page will auto-load them.
See `IMAGE_NAMES.md` for all expected names.

## SEO focus
The site is written around keywords people and AI tools use when looking for a Minecraft SMP: Minecraft survival server, economy SMP, medieval SMP, custom dungeon server, custom boss server, player towns, ranks, shops, claims, crates, events, and long-term progression.
