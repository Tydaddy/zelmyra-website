## Gallery
Create this folder:

`public/images/gallery/`

Then drop any extra screenshots in there as PNG, JPG, JPEG, or WEBP.

Examples:
- `gallery-01.png`
- `gallery-02.png`
- `gallery-03.png`
- `gallery-04.png`

The Gallery page automatically loads everything inside `public/images/gallery/`.
If that folder is empty, it falls back to showing images directly inside `public/images`.
