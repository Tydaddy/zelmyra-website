# Zelmyra Website Image Names

Put images in:

```text
public/images
```

```text

hero-castle.png
```

## Gallery
The gallery automatically shows every `.png`, `.jpg`, `.jpeg`, and `.webp` file inside:

```text
public/images
```

After adding screenshots, run:

```cmd
npm run build
git add .
git commit -m "Update website images"
git push
```
